# Bhargavi Portfolio

React + TypeScript + Vite + Three.js (React Three Fiber).

## Run
npm install
npm run dev

## Build
npm run build   (creates the "dist" folder)

## Edit
- Contact, email and resume: src/config/site.ts
- Content (projects, experience, etc.): src/data/
- Resume file: put Bhargavi_Resume.pdf in /public
